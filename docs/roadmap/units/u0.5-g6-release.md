cd ~/cucumber/production/src
export IMAGE_NAME=cucumber-production CUCUMBER_VERSION="$(cat ../current)"

  SELECT id, username, email, is_superuser, is_staff FROM auth_user

## Findings

1. **Staff notes take in the pull request's footer** (`scripts/staff_notes.py`).
   `_section_lines` keeps everything under `## Staff note` up to the next
   heading, so the `🤖 Generated with Claude Code` line at the end of a PR body
   joins the note; and "Nothing for staff." isn't in `NOTHING_TO_SAY`. Had the
   draft been published unchanged, Discord would have had that text. Fixed in
   the draft by hand for `2026.10.2`. Follow-up (test first, own PR, before the
   next release): stop the section at a blank line or the footer, and treat
   "Nothing for staff" as none.
