## Timing note (10× today)

`bash uat/timing_10x.sh` on this Mac (PostgreSQL 17 in Docker), 2026-10-20,
same data scale as U0.5 (100 accounts, 300 open sessions, 10,000 failed
tries; inventory at 10× today). Every save now checks the role, and the
inventory rows still match the U0.5 run within noise.

| Action | Median | p95 |
|---|--:|--:|
| Save an entry, typical batch | 4.9 ms | 7.5 ms |
| Save an entry, busy batch | 26.9 ms | 52.0 ms |
| Split | 10.5 ms | 16.6 ms |
| Void | 9.7 ms | 14.7 ms |
| Correction | 10.6 ms | 16.3 ms |
| Mark one queue item reviewed | 3.1 ms | 4.4 ms |
| Review queue, whole backlog | 1.58 s | 1.81 s |
| Log in, right password | 118.8 ms | 126.2 ms |
| Open a page, signed in | 3.6 ms | 5.3 ms |
| Staff page, all accounts (with roles) | 9.1 ms | 12.2 ms |
| Give someone a new password | 110.8 ms | 119.0 ms |

The Staff page went from 62 ms (U0.5) to 9 ms because G4's L5 fix looks the
roles up in bulk. Everything is far under the half-second a phone user would
notice.
