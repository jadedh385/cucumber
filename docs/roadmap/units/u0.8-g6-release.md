## Findings

1. **CI had been red for three G5 commits** because the formatter checks Python blocks in
   Markdown. Run `uv run ruff format` over any note with a code block before pushing.
2. **A G5 `--source` deploy hides the migrations from the tag deploy** ("no changes"). The
   rehearsal needs G5's pre-deploy copy too. Now in the runbook (§3).
3. **The restore script's health check must use `APP_PORT`**, not 8000. The app was fine.
4. **The staging home-network address refused SSH again; production's timed out.** The
   `-remote` aliases worked. Same as G5 finding 3.
5. **Cloudflare Access prints a login URL with a token** when it reconnects; it was not
   copied into this note.
6. **Old `ModelBackend` session** on production lingers until it is used or expires; not
   an issue.
7. Application code was not changed at G6.
