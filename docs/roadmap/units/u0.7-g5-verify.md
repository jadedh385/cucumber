## E2E on staging

Run by the Owner from their Mac, values typed hidden (Claude never saw them):
`E2E_SITE_URL=https://cucumber-staging.southeastcanopy.com`, the `cucumber-e2e`
Access token and the practice login, with `UV_ENV_FILE=.env` so Django can load.

**17 passed, 6 skipped in 8.4 s.** The six skips are by design: the five from
U0.6 (two account-changing U0.5 tests, "production shows no banner", and the two
role tests) plus the new U0.7 test in `e2e/test_deactivate.py` (the Admin
deactivates with a reason on a phone), which changes accounts and so runs only
against the local live server (where it passes).

A first run failed 5 tests (health, login pages, login form): Cloudflare Access
answered 401 to the token (a `curl` with the token showed it), so the tests never
reached the app. The staging app was healthy throughout. The token values were
re-entered and the same `curl` then gave 200.
